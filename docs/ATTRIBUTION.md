# Attribution and licensing

## Observation data

Source: NOAA National Centers for Environmental Information, Global Historical
Climatology Network hourly (GHCNh), contributing national/international observation
sources and the stations identified in the data card. Retrieved 23 October 2026.

- [Dataset overview](https://www.ncei.noaa.gov/products/global-historical-climatology-network-hourly)
- [Dataset metadata and use conditions](https://www.ncei.noaa.gov/metadata/geoportal/rest/metadata/item/gov.noaa.ncdc:C01688/html)
- [Documentation](https://www.ncei.noaa.gov/oa/global-historical-climatology-network/hourly/doc/ghcnh_DOCUMENTATION.pdf)

The original reports are not relicensed by this project. Raw/processed observation
files are excluded from the Git repository; provenance, cleaning audits, limited
evaluation tables and derived plots are retained. Preserve provider/source IDs
and consult the dataset metadata for the provider's citation and use conditions
when writing a paper. Public download access is not a blanket software license
for every contributing source product. No affiliation with NOAA or IMD is claimed.

## Software and derived artifacts

A software license has not yet been selected by the project owner. This repository

the limitations stated in the model/validation cards.
