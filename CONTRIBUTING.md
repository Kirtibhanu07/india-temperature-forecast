# Contributing

Use Python 3.12, install the pinned environment and editable package as shown in
the README, and run `python -m unittest discover -s tests -v` before proposing changes.

Keep raw downloads and credentials out of Git. Record input/source changes and
their fingerprints. Predictor engineering must be past-only; never impute labels.
Preserve the persistence baseline and matched evaluation pairs. Do not tune on
the exposed October test or replace it with only favourable periods.

For a model experiment, state the hypothesis, input availability times, validation
protocol, baseline and limitations. Commit tables alongside regenerated figures.
Update the model/data cards if behavior or scope changes. The code license is
currently undecided; discuss proposed contributions with the owner before submission.
